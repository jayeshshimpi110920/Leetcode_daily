### Two Sum — Question in 2 lines

Given an integer array `nums` and an integer `target`, find **two different elements** whose sum equals `target`.
Return the **indices** of those two elements.

**Example:**

```text
nums = [2, 7, 11, 15], target = 9
Output = [0, 1]

Because nums[0] + nums[1] = 2 + 7 = 9
```


Answer: 
1) **Brute force approach** : O(n²) || Space complexity : O(1)  using 2 for-loop using one by one each element
2) **Sorting + Two Pointer** :
3) **Hashmap (Optimal)** : Time: O(n) average  && Space: O(n)

create a hashmap and store value and index, only one cycle O(N)

search_in_hashmap_value = target - num[i]   

search this value if exist then just return the that simple.  

3) **Sorting + Two pointer**:

Sort the array, then keep one pointer at the start and one at the end.
If sum < target, move left++; if sum > target, move right--; if equal, we found the pair

### CODE : 

For **LeetCode #1 — Two Sum**, here are the main approaches from **brute force → optimal**, with time/space complexity.

### 1. Brute Force — Nested Loops

Check every pair.

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        for (int i = 0; i < nums.length; i++) {
            for (int j = i + 1; j < nums.length; j++) {
                if (nums[i] + nums[j] == target) {
                    return new int[]{i, j};
                }
            }
        }
        
        return new int[]{};
    }
}
```

**Complexity:**

* Time: `O(n²)`
* Space: `O(1)`

---

### 2. Sorting + Two Pointers

Sort the values, then use two pointers. But because the problem asks for **original indices**, we need to store each number with its original index.

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        int[][] arr = new int[nums.length][2];

        for (int i = 0; i < nums.length; i++) {
            arr[i][0] = nums[i]; // value
            arr[i][1] = i;       // original index
        }

        Arrays.sort(arr, (a, b) -> Integer.compare(a[0], b[0]));

        int left = 0;
        int right = arr.length - 1;

        while (left < right) {
            int sum = arr[left][0] + arr[right][0];

            if (sum == target) {
                return new int[]{arr[left][1], arr[right][1]};
            } else if (sum < target) {
                left++;
            } else {
                right--;
            }
        }

        return new int[]{};
    }
}
```

**Complexity:**

* Time: `O(n log n)` — sorting
* Space: `O(n)` — storing values + indices


* Creating `arr` with **value + original index** takes **O(n)**.
* Sorting that `arr` takes **O(n log n)**.
* Two-pointer traversal takes **O(n)**.

So overall:

```text
O(n) + O(n log n) + O(n)
       ↓
    O(n log n)
```

The **sorting dominates**, so the total time complexity is **O(n log n)**.

### 3. HashMap — Optimal

For every number, ask:

> "Have I already seen the number I need?"

If current number is `x`, we need:

```text
target - x
```

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        HashMap<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            int needed = target - nums[i];

            if (map.containsKey(needed)) {
                return new int[]{map.get(needed), i};
            }

            map.put(nums[i], i);
        }

        return new int[]{};
    }
}
```

**Complexity:**

* Time: `O(n)` average
* Space: `O(n)`

### Evolution

```text
Brute Force
   ↓
Nested loops
   ↓
O(n²) time, O(1) space

Sorting + Two Pointers
   ↓
Sort + left/right pointers
   ↓
O(n log n) time, O(n) space

HashMap
   ↓
Store previously seen numbers
   ↓
O(n) average time, O(n) space
```

**Interview explanation for the optimal approach:**

> "The brute-force approach checks every pair, giving O(n²). We can improve this by using a HashMap. For each element, we calculate its complement as `target - nums[i]`. If that complement is already in the map, we have found the pair. Otherwise, we store the current number and its index. This gives O(n) average time and O(n) space."
